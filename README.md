# Лемматизация текста (приведение к словарной форме) и добавление леммам частеречных тегов

## Техническое задание

Для решения задачи вы можете использовать данные, которые упоминались в лекциях: например, словарь oDict, разметку OpenCorpora и др. Для решения задачи нельзя использовать существующие морфологические анализаторы (mystem, pymorphy и т.п.).

### Ввод

Предложения вида " токен1 токен2 ... токенN" с расставленными знаками препинания, разделенные переносом строки. Из знаков препинания в предложениях могут содержаться только запятая, точка, вопросительный и восклицательный знаки.

### Вывод

Для каждого предложения из входных данных вывод в виде " токен1{лемма1=тег1} токен2{лемма2= тег2} ... токенN{леммаN=тегN}" без исходных знаков препинания. Разделитель между токенами -- пробельный символ.

### Замечание

При лемматизации буквы е и ё, а также написание с прописной/строчной буквы признаются равноправными. Не забываем про неизвестные слова и оценку точности.

### Пример

Input:
Стала стабильнее экономическая и политическая обстановка, предприятия вывели из тени зарплаты сотрудников.
Все Гришины одноклассники уже побывали за границей, он был чуть ли не единственным, кого не вывозили никуда дальше Красной Пахры.
Output:
Стала{стать=V} стабильнее{стабильный=A} экономическая{экономический=A} и{и=CONJ} политическая{политический=A} обстановка{обстановка=S} предприятия{предприятие=S} вывели{вывести=V} из{из=PR} тени{тень=S} зарплаты{зарплата=S} сотрудников{сотрудник=S}
Все{весь=NI} Гришины{гришин=A} одноклассники{одноклассник=S} уже{уже=ADV} побывали{побывать=V} за{за=PR} границей{граница=S} он{он=NI} был{быть=V} чуть{чуть=ADV} ли{ли=ADV} не{не=ADV} единственным{единственный=A} кого{кто=NI} не{не=ADV} вывозили{вывозить=V} никуда{никуда=NI} дальше{далеко=ADV} Красной{красный=A} Пахры{Пахра=S}

## Решение

Было выбрано использовать разметку OpenCorpora, так как она - один из популярных и легкодоступных датасетов, содержащих начальные формы слов с частями речи русского языка.
Для определения частей речи было выбрано сделать самую простую нейронную сеть прямого распространения/с прямой связью.
Для подачи слов было решено использовать следующие правила:

1. Подавать слова в обратном порядке, чтобы окончания, по которым обычно определяются части рече находились в одном месте (в начале)
2. Подавать слова побуквенно в формате массивов размерами равными мощности алфавита (каждый нейрон - один элмент массива). Со значениями: 1 на месте индекса буквы и 0 в остальных местах

Эксперимент дал логичные результаты. См. result_draft.txt. Демонстративнее всего является рассмотрение частицы "ли". Тест определил ее, как глагол, так как часто глаголы заканчиваются на ли (жили, делали и т.п.), поэтому архитектура является несостоятельной.

Если идти в сторону нейронных сетей дальше, то нужно разбираться в RNN, чего делать для лаб. работы не хочется, поэтому было решено заменить архитектуру на обычный поиск в словаре датасета. В качестве оценки точности было выбрано использовать количество найденных слов ко всем в предложении. Результаты см. в result_main.txt.

## Инструкция

Для использования скачайте [разметку OpenCorpora](https://opencorpora.org/dict.php) и поместите файл dict.opcorpora.xml в папку, из которой будет запускаться main.py.
